# The Persona Duel: AI & The Emerging Market Job Landscape

A structured AI debate project exploring how personality, tone, and context shape machine learning outputs. This project utilizes the **ROLE** and **CREATE** frameworks to simulate a high-stakes discussion between two distinct professional personas.

## 🎯 Project Overview
The goal of this project is to demonstrate mastery of prompt engineering by building two detailed AI personas and making them debate a real-world topic: **"The impact of AI on job creation in emerging markets."**

## 🛠️ Frameworks Used
- **ROLE Framework**: Used to define the Role, Objective, Language, and Era/Context for each persona.
- **CREATE Framework**: Used to structure the iterative prompts for the 5-round debate flow (Context, Role, Expectation, Action, Target, Examples).

## 👥 The Personas

### Persona A: The Global CEO
* **Profile**: Tier-1 Silicon Valley Venture Capital Executive.
* **Style**: Formal, data-driven, assertive, and jargon-heavy.
* **Perspective**: Focuses on global scalability, ROI, and long-term technological disruption.

### Persona B: The Local Founder
* **Profile**: Nairobi-based Startup Founder (Logistics/Tech).
* **Style**: Relatable, practical, direct, and street-smart.
* **Perspective**: Focuses on "on-the-ground" realities, infrastructure gaps (power/internet), and community-driven economic resilience.

## 📂 File Structure
* `index.html`: The main presentation layer featuring the structured debate transcript and final analysis.
* `style.css`: Custom stylesheet with color-coded dialogue bubbles to distinguish between the Global CEO and Local Founder.
* `README.md`: This documentation file.

## 📝 Key Insights
The debate revealed that while the Global CEO offers a compelling macroeconomic vision of "leapfrogging," the Local Founder provides a more convincing argument by addressing the **implementation gap**. The project successfully demonstrates that persona-driven prompting prevents generic AI outputs and forces a clash of values—specifically **Efficiency vs. Livelihood**.
